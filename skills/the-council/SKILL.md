# The Council

Force a question through deliberately different ways of thinking, then commit to one answer.

1. Frame the question and what a good decision looks like (constraints, time, money, risk appetite).
2. Five frames, each independent: **Contrarian** (why this fails), **First Principles** (what is actually true from the ground up), **Expansionist** (the bigger opportunity being missed), **Outsider** (how someone with no context sees it), **Executor** (what it takes to actually do it next week). Add 1–3 domain specialists when the topic needs them.
3. Blind peer review: each frame critiques the others' strongest points without knowing who wrote them.
4. One verdict, the reasoning that decided it, what would change the verdict, and ONE clear next step with a date.
Use the latest council version in the reference material; older variants are there for comparison.
